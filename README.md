# ⚡ Calculadora de Consumo Elétrico

## 📌 Sobre o projeto

Este projeto calcula o consumo elétrico desenvolvida em Python.

O programa permite que o usuário informe o nome de um aparelho, sua
potência em watts e o tempo médio de uso diário. A partir dessas
informações, o sistema calcula uma estimativa do consumo de energia
elétrica durante um mês.

Além do consumo mensal, o programa também apresenta uma estimativa de
custo com base em um valor fixo de R$ 0,75 por kWh.

## 🎯 Objetivo

O objetivo do projeto é auxiliar o usuário a entender e estimar o
consumo de energia elétrica de aparelhos utilizados no dia a dia.

## 🐍 Linguagem utilizada

- Python

## 📐 Fórmula utilizada

O consumo mensal é calculado utilizando a seguinte fórmula:

consumoMensal = (potência × horasDia × 30) / 1000
